# Pixel-Perfect Keyboard Layout Fix

## Проблема
Координаты свайпов не совпадали с датасетом `keys_full.csv` из-за того, что поле ввода и кнопки управления сдвигали клавиатуру вниз.

## Решение
Клавиатура теперь:
- ✅ Имеет **строго фиксированный размер** 1080×631 px
- ✅ **Начинается с координаты (0, 0)** относительно `keyboardContainer`
- ✅ **Не имеет отступов** (margin: 0, padding: 0)
- ✅ Элементы управления **не влияют** на позицию клавиатуры

## Два варианта layout

### 1. Горизонтальный (рекомендуется) - `index.html`
```
┌──────────────────┬─────────────┐
│                  │  Поле ввода │
│   Клавиатура     │  Предсказать│
│   1080×631px     │  Принять    │
│                  │  Исправить  │
└──────────────────┴─────────────┘
```
- Клавиатура слева
- Панель управления справа
- Требует широкий экран (~1400px)

### 2. Вертикальный - `index-vertical.html`
```
┌──────────────────┐
│   Клавиатура     │
│   1080×631px     │
└──────────────────┘
┌──────────────────┐
│  Поле ввода      │
│  Предсказать     │
│  [Блок управления]
└──────────────────┘
```
- Клавиатура сверху
- Панель управления снизу
- Для узких экранов

## Ключевые изменения

### `index.html`
- Layout: `display: flex; gap: 20px;`
- Клавиатура: фиксированный размер, `flex-shrink: 0`
- Управление: отдельный блок справа
- `body { margin: 0; padding: 0; }`

### `main.css`
```css
.keyboardContainer {

  padding: 0 !important;
```

## Как проверить

### 1. Откройте браузер
```bash
cd apps/frontend/demo
# Открыть index.html в браузере
```

### 2. Откройте DevTools (F12) → Console

### 3. Сделайте свайп на клавиатуре

### 4. Проверьте координаты в консоли
Для буквы **"й"** (левый верхний угол):
- Ожидаемые координаты: `x: ~49.5, y: ~92.0` (центр клавиши)
- Из датасета: `x1=0, y1=15, x2=99, y2=169` → центр `(49.5, 92.0)`

Для буквы **"х"** (правый верхний угол):
- Ожидаемые координаты: `x: ~1031.0, y: ~92.0`
- Из датасета: `x1=982, y1=15, x2=1080, y2=169` → центр `(1031.0, 92.0)`

### 5. Сравните с датасетом
```bash
cd apps/frontend
head -5 keys_full.csv
```

## Диагностика проблем

### Клавиатура не 1080×631
```javascript
// В консоли браузера
const kb = document.querySelector('.simple-keyboard');
console.log(`Размер: ${kb.offsetWidth}×${kb.offsetHeight}`);
```
Должно быть: `1080×631`

### Canvas не совпадает с клавиатурой
```javascript
const canvas = document.querySelector('.swipeCanvasElement');
console.log(`Canvas: ${canvas.width}×${canvas.height}`);
```
Должно быть: `1080×631`

### Координаты сдвинуты
Проверьте, что `keyboardContainer` начинается с (0, 0):
```javascript
const container = document.querySelector('.keyboardContainer');
const rect = container.getBoundingClientRect();
console.log(`Position: (${rect.left}, ${rect.top})`);
```
Должно быть близко к `(10, 10)` (padding от body).

## Преимущества нового layout

1. ✅ **Координаты точные** - клавиатура не сдвигается
2. ✅ **Удобно тестировать** - всё на одном экране
3. ✅ **Консистентность** - координаты свайпов = координатам датасета
4. ✅ **Масштабируемость** - легко добавить больше контролов справа/снизу
